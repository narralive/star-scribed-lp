# star-scribed | Beyond the Poster

GitHub Pages-ready, responsive static site. No build system, scripts, or backend.

## Publish

1. Create a GitHub repository.
2. Upload the **contents** of this folder (not the containing folder) to the repository root.
3. In the repo choose **Settings → Pages → Deploy from a branch → main / (root)**.
4. After the site goes live, put the resulting Pages URL into your poster QR code. A project URL typically looks like `https://USERNAME.github.io/REPOSITORY/`.

## Editing

Edit `index.html` to update the research and `style.css` to adjust the presentation. `assets/` contains original poster/paper project imagery. All features not yet implemented are labelled as concepts. As the work advances, adjust those status labels accurately.
